# Estrutura de Dados

Repositório criado para armazenar os exercícios, atividades e projetos desenvolvidos ao longo da disciplina de **Estrutura de Dados**, do curso de Bacharelado em Sistemas de Informação (CEFET-MG).

## 🎯 Sobre

Este repositório reúne implementações práticas dos principais conceitos estudados na disciplina, com foco no entendimento da lógica por trás de cada estrutura — não apenas no resultado final.

## 🛠️ Tecnologias

- Python

## 📂 Organização

Cada atividade é organizada em sua própria pasta, contendo o(s) arquivo(s) referentes ao exercício proposto.

```
├── Atividade01/
├── Atividade02/
└── ...
```

## 🚀 Como executar

```bash
python3 nome_do_arquivo.py
```

## 📌 Observações

Este repositório tem fins **acadêmicos e de aprendizado**, sendo atualizado conforme o andamento da disciplina.
